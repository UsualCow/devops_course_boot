Combat Advantage
Fantasy Quest doesn't have any way for players to know if they are strong enough to hold their own against certain enemies.

If a player's power level is greater than the enemy's defense, that player has an "advantage"

If the player's power and enemy's defense are equal, they are "evenly matched"

Otherwise, that player has a "disadvantage".

Assignment
Complete combat_evaluation with an if/elif/else block that compares player_power and enemy_defense using the rules above. The three result variables start as False.

Set only the matching variable (advantage, disadvantage, or evenly_matched) to True.

Leave the existing return at the bottom to return all three values. Don't return anywhere else.
